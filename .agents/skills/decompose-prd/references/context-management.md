# Gestão de Contexto para PRDs Extensos (>50 páginas)

Diretrizes para ingerir e processar documentos extensos sem estouro de tokens ou alucinação.

## Estratégia de Fragmentação (Semantic Chunking)
1. **Chunking por Seções Maiores:** Dividir o PRD por capítulos conceituais.
2. **Extração de Sumários Hierárquicos:** Criar um mapa de contexto global com referências cruzadas.
3. **Passagem de Contexto Mínimo Viável:** Cada tarefa recebe apenas o contexto de seu Épico e dependências imediatas.
