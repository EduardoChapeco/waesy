# Geração Dinâmica de Temas Sob Demanda (Dynamic Theme Generation)

> **Objetivo:** Algoritmo heurístico para sintetizar novos temas personalizados a partir de palavras-chave conceituais.

---

## 1. Mapeamento Semântico de Conceito para Matiz (Hue)

- **Saúde, Medicina, Calma:** Matiz 190-210 (Cyan / Azul Claro) ou 140-160 (Verde Menta).
- **Finanças, Governança, Luxo:** Matiz 220 (Azul Marinho) + Acentos Dourados (45-50).
- **Energia, Juventude, Criatividade:** Matiz 320-340 (Magenta) e 25-35 (Laranja Vivo).
- **Ecológico, Sustentável, Orgânico:** Matiz 120-150 (Verde Musgo e Sálvia).
