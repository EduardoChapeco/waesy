# Triangulação de Dados de Pesquisa

A regra fundamental para não construir produtos baseados em falsas pistas.

## O Triângulo de Validação
1. **O que as pessoas DIZEM (Qualitativo / Entrevistas):** Revela motivações, expectativas e modelos mentais.
2. **O que as pessoas FAZEM (Telemetria / Mixpanel / Analytics):** Revela comportamento real, funis de abandono e tempo de uso.
3. **Quantas pessoas compartilham disso (Quantitativo / Surveys):** Revela representatividade estatística.

Nunca tome decisões drásticas de arquitetura ou remoção de features sem a convergência dos 3 lados do triângulo.
