# Métricas Core Web Vitals & Benchmarking

Metodologia de mensuração dos indicadores vitais da Web.

## Limiares Oficiais (Google / W3C)
- **LCP (Largest Contentful Paint):** Bom <= 2.5s | Precisa de Melhoria <= 4.0s | Pobre > 4.0s
- **INP (Interaction to Next Paint):** Bom <= 200ms | Precisa de Melhoria <= 500ms | Pobre > 500ms
- **CLS (Cumulative Layout Shift):** Bom <= 0.1 | Precisa de Melhoria <= 0.25 | Pobre > 0.25
- **TTFB (Time to First Byte):** Bom <= 800ms | Pobre > 1800ms
- **FCP (First Contentful Paint):** Bom <= 1.8s | Pobre > 3.0s
- **TBT (Total Blocking Time):** Bom <= 200ms | Pobre > 600ms
