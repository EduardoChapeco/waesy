# Detecção Ativa de Desvios (Change Sensing)

Prevenção de divergência entre a intenção de produto e o código em produção.

## Rastreio de Mudanças Ocultas
- **Revisão Semanal de Pull Requests:** Verifique se as alterações técnicas respeitam os limites de escopo do PRD.
- **Monitoramento de Canais de Suporte e Vendas:** Identifique quando a equipe comercial está prometendo recursos inexistentes.
- **Reconciliação de Documentação:** Atualize imediatamente os diagramas e contratos de API quando uma mudança for aprovada.
