# Análise de Dados de Produto & Telemetria

Decisões embasadas em evidências quantitativas:

## KPIs Canônicos por Estágio
- **Aquisição:** Taxa de conversão de visita para cadastro.
- **Ativação:** Tempo até o "Aha! Moment" (primeira venda ou compra).
- **Retenção:** Análise de coortes semanais D1, D7, D30.
- **Receita:** GMV transacionado, Take-rate líquida, MRR.
- **Indicação:** NPS real e coeficiente de viralidade ($K > 1$).
