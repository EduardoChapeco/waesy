# Modelo Canônico de PRD para Engenharia

Estrutura formal de um PRD de classe mundial:
1. **Resumo Executivo & Problema:** 1 parágrafo explicando a dor.
2. **Métricas de Sucesso:** Metas quantificadas (ex: conversão $+15%$).
3. **Personas & Jornadas:** Como o usuário navega na nova funcionalidade.
4. **Requisitos Funcionais (EARS):** Declarações numeradas [EARS-1]..[EARS-N].
5. **Requisitos Não-Funcionais:** Latência, segurança, RLS, acessibilidade WCAG 2.2 AA.
6. **Fora do Escopo:** Limites explícitos para conter expansão indevida.
