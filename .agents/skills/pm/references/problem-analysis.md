# Análise de Problemas & Resolução de Crises (RCA)

Quando uma métrica desaba ou um bug crítico afeta a operação:

## Técnica dos 5 Porquês
1. Descubra o sintoma visível.
2. Questione a causa imediata.
3. Identifique a falha no processo ou sistema.
4. Mapeie a ausência de barreira defensiva.
5. Chegue à causa raiz organizacional ou de arquitetura.
